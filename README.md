# module-package-by-example

This repository is for you to train on importing your modules correcting.\
Using the __init__.py files to import from the sub-packages more neatly.

Make sure you create a branch for yourself, and after you do your changes\
 you will need to create a pr (pull request) to the main so that I can review them.

## Requirements

1- Create an 
.py file for the math_utility and string_utility modules\
so that we can import their content more neatly and easily.\
2- In the mult.py module, import the edit method from printing.py.\
3- In the concatenation.py module import the addition method from the add.py.\
4- In the main import everything from the utilities and use them in an example.\


## Extra (Homework-Required)

5- To make the importation in the main even more clean. We can create an __init__.py\
file in the utilities package and import the things we need.\
Thus we can import everything from the utilities package directly with out \
calling the sub-packages.
